## Known Limitations

- Windows 实际关机/登录后通知补查及当前版本通知点击全链路尚未完整实测。
- 第二块物理磁盘移动尚未实测；跨卷结果不能代替。
- 卡片/列表、置顶、最近数量等 localStorage 偏好不纳入 SQLite 备份；主题本身保存在 SQLite。
- 使用统计约 15 秒心跳，异常退出可能丢最后片段；搜索每类最多 50 项；媒体受浏览器编码支持限制。
- 长期大规模使用、全部 512 MiB/媒体边界、既有窄屏长标题及附件 UI 验证缺口继续保留。
- 本地服务实机冷启动已在本轮独立库补验通过；正式数据新副本完整性未在本轮扩大复查，不能用业务文件指纹不变代替新检查。Phase 8.2 的历史证据仍按原报告保留。
- 当前环境仍不能写原日志，已通过启动容错处理；此时仅保留窗口输出，关闭后不会补写。正常可写环境仍追加文件。

未实测不等于失败。当前没有已确认的 Critical / High 发布阻塞；已知边界保留，不把历史受阻记录当作当前验收失败。
