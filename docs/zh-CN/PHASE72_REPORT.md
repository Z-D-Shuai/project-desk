## 使用方法

1. 双击项目根目录 start.bat，自动打开 http://127.0.0.1:4317，无需npm install。
2. 项目档案选择状态、分类、归档和排序；高级筛选中搜索项目名称。卡片/列表按钮记忆当前浏览器偏好。
3. 顶部昼夜滑块点击切换、拖动调整，右侧箭头展开并选择跟随系统。Ctrl+K搜索、快速操作和通知入口保留。
4. 需要停止服务时运行stop.bat；仅关闭浏览器不会停止Node服务，独立Windows提醒机制继续按原设置运行。
