# PROJECT DESK

PROJECT DESK 是一个面向 Windows 10 / 11 的本地优先项目管理与数字资料档案馆。它把项目、进度、开发日志、资料、提醒与跟进整理在同一个工作台中；数据保存在用户自己的电脑，无需账号或云服务。

## 运行环境

使用前需要自行安装第三方运行环境 **Node.js 24.x**（Windows x64）。请从 [Node.js 官方下载页](https://nodejs.org/en/download) 获取并安装。项目没有其他第三方运行依赖，不需要执行 `npm install`。应用不会替用户安装或升级 Node.js。

## 启动

安装 Node.js 后，解压项目文件夹并双击根目录的 **`start.bat`**，浏览器会打开 `http://127.0.0.1:4317`。使用 **`stop.bat`** 停止服务。也可在项目目录打开终端并运行 `npm start`。关闭浏览器标签页不会自动停止服务。

## 当前能力与范围

- 总览、项目档案、跟进中心、资料库及设置入口，可导航、刷新和使用浏览器前进后退。
- 浅色、深色、跟随系统主题，设置保存到 SQLite。
- 统一布局、颜色/字体/间距变量、图标、按钮、输入框、面板、空状态、对话框和侧面板。
- 本地 SQLite 初始化、版本化迁移、数据库约束、读取状态与错误重试。
- 项目创建、编辑、删除，五种状态与 0–100 整数完成度分别管理，进度以圆环展示。
- 自定义项目分类、内置图标或自定义符号、收藏与上移/下移排序；删除分类时转移项目。
- 名称搜索、分类/状态筛选、创建/更新时间双向排序、独立详情页、归档与恢复、总览统计及最近项目。
- 正式数据库不预置示例项目、收藏或开发日志；常用预设独立保存，选用后才生成实际分类或参与者。

已支持自定义参与者、项目与日志的两级关联、开发日志/重要节点、日期及参与者筛选、当前工作备忘和全局跟进汇总。已支持数字资料库及基本文件上传预览；已支持文件批量导入、本地存储管理、回收站、备份与恢复。已支持提醒与回访；已支持全局搜索、使用统计、常用预设和快速操作；全量导出及自动定时备份尚未实现。当前为本地浏览器工作台，尚未桌面封装。

## 项目档案操作

从总览或项目档案点“新建项目”。仅名称必填；简介、分类、状态和完成度可按需填写。点击项目名称进入详情，详情页可编辑、归档/恢复及删除。

项目列表默认显示未归档项目。在顶部“归档范围”中切换“已归档”或“所有项目”，也可选择创建/更新时间的升降序。筛选条件保留在当前地址中；返回列表时沿用本次筛选。列表每页最多 30 项。

“管理分类”支持改名、图标选择或最多 4 字符自定义符号、收藏和排序。收藏分类会出现在项目列表的快捷入口。删除分类需选择转移目标，默认“未分类”，不会删除其项目。

**归档不改变原状态、分类或进度，可随时恢复。** 总览统计包含归档项目，不包含已删除项目；最近更新包含归档项目，显示数量可在总览选择 1–12 项，偏好保存在当前浏览器。

删除项目需确认。当前采用数据库软删除，项目从列表、详情和统计中移除，原数据库行与关联保留，不删除磁盘文件。本阶段没有“撤销删除”界面，需要保留的项目优先使用归档。编辑检测到其他窗口已修改时，会提示刷新，避免旧表单覆盖新内容。

## 数据与恢复

数据库及 WAL/SHM 文件只在服务端访问，不通过静态文件服务暴露。默认数据放在项目 `data` 目录；可通过 `PROJECT_DESK_DATA_DIR` 指定其他本地目录（启动前设置，换目录不会自动迁移原数据）。上传文件独立保存在该数据目录的 assets 子目录，不写入 SQLite。

推荐使用设置中的“备份与恢复”，同时保存数据库、托管文件和校验清单。手工冷备份需先停止服务，再复制整个 data 目录及所有自定义托管目录；仅复制 data 不会包含外部托管目录。不要在运行期间单独复制或替换 SQLite 文件。

v1.0.0 恢复切换前写入 `.restore-state.json`。中断后再次启动会校验相关数据库的摘要、完整性与外键，优先找回恢复前工作台，或完成已安装的候选库；不猜测覆盖未知内容。旧版中断没有此标记、主库又缺失时，会明确拒绝新建空库。此时保留 `before-restore-*.sqlite`、`restore-*.sqlite`、`restored-*` 和 `recovery/`，在确认所需版本后再安排恢复，不手工删除或改名猜测。

检查与恢复使用独立 `.reminder-data-mutex.sqlite` 互斥文件，不增加业务表或迁移；它是运行协调文件，不纳入应用备份。进程退出由系统释放互斥。兼容 PID 锁 `.reminder-data.lock`，存活持有者仍会等待；旧空锁短暂等待后可恢复，被接管的元数据保存为 `.abandoned-*`，便于排查。

更多见 `docs/ARCHITECTURE.md`、`docs/DATA.md`、`docs/PROGRESS.md`。

## 阶段 2 使用方式（v0.2.0）

在“跟进中心 → 管理 AI / Agent”维护名称、类型和用途/职责，名单完全由用户添加。
项目详情的“关联参与者”保存项目总体名单；“记录开发日志”仅填写一句修改内容即可保存。展开“详细编辑”可填写标题、日期、文件/功能、结果、问题、下一步与说明。每条日志独立勾选实际参与者，新增选择会同时补入项目名单，但项目名单不会自动成为日志名单。

时间线可按日期、日志参与者、重要节点、时间顺序筛选；全局跟进中心另可按项目筛选。日期按本机本地日历日、含起止日处理；保存时间统一为 UTC。日志中“查看修改详情”可展开所有详细字段，编辑和删除都在记录旁操作。

“编辑备忘”维护当前工作、问题、想法和下一步；它与日志分别保存，不会自动或重复生成日志。跟进中心汇总所有仍可见项目的非空备忘，包括带明确标记的归档项目。

删除参与者后不再允许新关联，原项目和日志保留名称及“已删除”标记。若某参与者仍被项目日志引用，不能从该项目总体名单移除。日志使用软删除；当前界面不提供删除恢复。修改存在版本冲突时请关闭编辑框并刷新后再操作。

以上为阶段 2 的操作说明。当前已开放资料收藏、文件管理和阶段 5 的自动提醒；模型 API 接入未实现。

## 阶段 3 使用方式（v0.3.0）

进入“资料库 → 新增资料”，选择视频收藏、图片、网页、文字、附件或本地视频。网址需完整 http/https，视频来源平台自由填写；文字资料直接编辑正文；图片、视频和附件选择本地文件，保存时复制入库。单文件最多 512 MiB。已有资料类型不直接转换，其他字段可随时编辑。

“管理分类与收藏夹”内切换管理内容，可新增、改名、排序和删除资料分类、标签、收藏夹；分类还可设置图标。分类是单一主要归属，标签是多选特征，收藏夹是多选主题集合。“收藏”是独立快捷标记，不改变这些整理关系。删除分类时选择转移到其他分类或未分类，删除标签/收藏夹只移除整理关系。

编辑资料展开“标签、收藏夹与项目关联”，可一次选择多个项目；项目详情也能点“关联已有资料”进行勾选。两处共享同一条资料及同一个文件。已收藏的相同网址会提示使用已有记录，避免重复收藏副本。

列表支持名称搜索、类型/分类筛选，在“更多筛选与排序”中按标签、收藏夹、状态、收藏标记筛选和按收藏/修改时间双向排序。每页 30 份，筛选保存在当前地址中。窄窗口默认收起次要筛选。

资料详情提供内容预览、编辑、收藏切换和关联项目跳转。图片支持 PNG、JPEG、GIF、WebP；本地视频支持 MP4、WebM、Ogg 容器，能否播放由浏览器编码支持决定，不支持时下载后使用本地播放器。其他文件作为下载附件，不执行或内嵌 HTML、代码。

“未整理 / 待查看 / 学习中 / 已学会 / 已使用 / 已归档”由用户手动修改；查看和下载只更新最后查看时间，不代表已学会或使用。收藏时间固定为新增时间，修改时间另行记录。

删除资料需确认，当前仅从浏览和项目关联区隐藏，原数据库行、历史关联与磁盘文件保留；阶段 4 已提供资料回收站恢复入口。需要保留可访问资料时，优先设为“已归档”。替换文件保留旧资产，文件清理与恢复见下文阶段 4。资料信息先保存、文件随后上传；上传失败会明确提示并保留表单，可重试或稍后进入编辑补传。

以上为阶段 3 操作说明。后续能力见下文，最新状态见 PROJECT_STATUS.md 和 docs/PROGRESS.md。

## 阶段 4 使用方式（v0.4.0）

**存储位置：**设置 → 存储目录设置。可编辑图片、视频、附件、项目文件的默认目录，也可新增其他目录。点“选择目录”在应用内切换磁盘、进入文件夹或输入地址后“转到”，再选择当前目录。已有内容迁移需勾选确认，并选择空目标目录；不覆盖同名内容。原磁盘不可用时，可选择内容一致的新位置并勾选重新定位。

**导入：**资料库 → 文件管理 → 导入文件。复制入库支持拖拽多文件、浏览器选择或本地选择器；引用使用本地选择器或每行一个完整路径。可同时勾选多个项目。相同内容优先复用已有资料，不复制项目副本；每项显示成功、复用或错误。浏览器每文件最多 512 MiB，本地路径复制/引用无此上传限制；每批最多 200 项。

**组织：**已登记文件中查看大小、实际路径、关联资料、可用性、预览与操作。目录浏览可创建子文件夹、移动/改名及回收文件夹。托管文件移动会更新共享引用；外部引用只读管理，不提供修改原文件按钮。路径失效时用“重新定位”，默认核对 SHA-256，内容不同需要勾选明确允许替换。项目详情可关联或创建本地项目目录，解除只删除关联。

**删除：**删除资料记录不会删除文件；解除项目关联不会删除资料；移入文件回收站会影响使用该文件的资料和项目，并要求确认。回收站分别显示资料记录与文件/文件夹，支持恢复。原位置有同名内容时不会覆盖，可修改恢复路径。永久删除需输入“永久删除”；删除记录仍保留真实文件，删除托管回收内容才永久移除字节。外部引用永久删除也不会删除原文件。

**备份：**设置 → 备份与恢复 → 选择保存目录 → 开始备份。每次生成独立 PROJECT-DESK-* 目录包；请完整保留 manifest.json、project-desk.sqlite 和 blobs。包含全部项目、AI/日志/备忘、分类/标签/收藏夹、关联、已登记托管文件、托管项目文件夹中的内容及回收内容。外部引用只记录路径，不打包原文件。其他未导入的外部目录内容不自动备份。托管文件缺失时默认拒绝完整备份，明确允许后可保存非完整备份。

**恢复：**选择含 manifest.json 的备份包目录 → 检查备份 → 恢复此备份 → 输入“恢复”。校验数据库和文件摘要；恢复会替换当前工作台记录，自动保存恢复前安全备份。托管文件恢复到 data/restored-* 中独立的新目录，原托管目录不覆盖，目录设置同步更新；外部引用仍使用原路径并提示失效。安全备份在 data/recovery 中。目前支持 005、006、007 目录包，旧包自动迁移；开发前的源码 ZIP 是工程快照，不能直接作为此界面的备份包使用。

备份期间暂停其他应用写操作。未完成备份保留 INCOMPLETE 标记，不能恢复；中断文件移动会尽量恢复登记状态或保留两份内容并显示待检查。备份未压缩或加密，请自行保管。符号链接不跟随，大规模目录和第二块物理磁盘尚未做性能验收。自动定时备份未实现；提醒和智能回访见阶段 5。

启动仍为双击 start.bat，无需安装依赖。阶段 5 说明见下文。详细验证见 docs/PROGRESS.md。

## 阶段 5 使用方式（v0.5.0 新增，继续保留）

**打开回访：**顶部“回访中心”，或总览的待回访入口。默认显示到期项目与资料，可按项目、类型和本地到期日期筛选，或切换稍后、暂停、未到期、排除及全部。暂停条目可恢复。底部展开已处理历史，最近 300 条可见，旧记录仍保存在 SQLite。

**配置规则：**设置 → 提醒规则与 Windows 通知。默认项目 30 天、资料 60 天、重复通知间隔 7 天、稍后 7 天；均可改为 1–3650 天整数。项目和资料可分别关闭。分类可设置不同周期；列表每项“独立规则”可覆盖，留空继承。继承分类周期时也继承分类暂停；设置单条周期可独立覆盖分类。

**实际跟进：**项目只默认提醒进行中且未归档的项目。普通改名、分类、进度和文件整理不重置闲置；日志事件/实际保存、非空工作备忘、手动继续跟进计为实际活动。没有活动时从创建时间算。继续跟进不修改项目状态或完成度。

**资料处理：**从收藏和最后查看的较晚时间算周期。去查看只记录查看与处理时间，不表示已学会/已使用；这两项由按钮明确确认，和已归档一样退出普通回访。删除资料进入资料回收站，不删除真实文件。本次已处理保留对象状态，按重复间隔再考虑回访；新跟进/查看则同时延后其原周期。应用内未处理条目仍显示到期，桌面提示不会每次检查都弹。

**Windows 通知：**先开启系统通知，再在提醒设置点“安装 / 更新时间”，并点“发送测试通知”。每天按设置时间和登录时用同一个当前用户任务检查；错过每日触发由 StartWhenAvailable 和登录检查补充。电脑关机或未登录时不能显示横幅，下一可用用户会话检查。不联网，不调用模型，不依赖主服务。

修改已安装任务的每日时间并保存，会更新同一任务；关闭全局提醒会卸载任务。全局重新开启只恢复应用内提醒，系统任务仍需明确安装。点“关闭并卸载”清理该实例任务、开始菜单标识和 URL 协议，不删除项目/资料/处理历史。Windows 勿扰可能抑制横幅，查询系统状态和最近投递可辅助排查。

通知汇总多个到期内容，可进入回访中心或具体对象。服务未运行时，通知入口会在后台启动本地服务；**关闭浏览器不会终止服务**。双击 **stop.bat** 可停止服务，Windows 任务仍独立保留。要停止后台提醒请在设置卸载。自定义端口/数据目录时，start/stop 应使用相同 PROJECT_DESK_PORT / PROJECT_DESK_DATA_DIR 环境变量；停止入口会核对数据库位置，拒绝停止其他实例。

检查日志：data/reminders/checker.log；通知入口日志：data/reminders/activation.log。系统任务名 PROJECT-DESK- 后接数据路径摘要，每个数据目录一项。通知开关属于 Windows 用户设置，本工具不会擅自开启全局通知。更换程序/数据位置前先卸载旧任务，移动后重新安装。

备份继续包含提醒规则、处理历史与通知去重记录；目前支持 005、006、007 目录包，旧包自动迁移到当前版本。整库恢复会关闭当前 Windows 任务，完成后重新启用。备份包应完整保管。

命令行辅助（在项目目录）：node scripts/manage-reminders.mjs status / install / uninstall / test / run；检查器为 node scripts/check-reminders.mjs。需要其他数据目录可加 --data 完整路径。这些命令与 UI 共用同一规则，通常使用界面即可。

阶段 5 能力继续保留。测试详情见 docs/PROGRESS.md；当前状态见 PROJECT_STATUS.md。


## 阶段 6 使用方式（v0.6.0）

- **设置 → 使用统计**：累计、今日、近 7/30 天、启动次数、平均单次和最近使用；30 天趋势与可展开的每日明细。点“刷新统计”立即保存当前片段并读取结果。
- **项目详情 → 使用情况**：打开次数、有效停留、平均停留和最近打开；刷新组件不会重复记访问。浏览统计不更新项目开发时间，不重置闲置提醒。
- **设置 → 常用预设库**：项目分类、AI / Agent、视频平台共用一个管理界面，可新增/编辑/删除、上移/下移、自定义符号和上传图片（PNG/JPEG/GIF/WebP，最多 2 MiB）。恢复默认仅补齐当前分组缺失的默认名称，不覆盖已编辑或自定义项；改名后的项保留，原默认名称可重新补回。
- **选用预设**：新建/编辑项目的分类菜单可从预设创建实际分类；新增参与者可选择预设后再改名称、类型和职责；视频表单的平台输入可选择候选或直接自由填写。预设不限制选项。删除预设不改变已保存的分类、参与者、日志和平台信息；历史图片引用继续保留。
- **全局搜索**：顶部输入后回车，或 Ctrl+K 聚焦。窄窗口点“搜索”打开独立页面。覆盖项目名称/简介、日志各内容字段、参与者、资料标题/网址/正文/备注/平台、项目及资料分类、标签。按类型分组，每组最多显示 50 项；日志结果展开并定位对应记录，参与者结果进入档案。已删除内容排除，归档记录仍可搜索。
- **快速操作**：顶部入口可新建项目、记录日志、收藏视频/网页、保存文字。总览也有快捷按钮；项目详情中快速收藏默认勾选当前项目。总览最近活动来自真实项目、日志和资料修改，保留待回访摘要；浏览时长不会产生开发活动。

计时以页面可见、获得焦点且最近 10 分钟有输入/指针活动为准。切后台、失焦或达到空闲阈值后暂停，重新活动继续。软件“启动次数”按工作台页面加载定义，刷新整页也计一次；普通页面切换不计新启动。平均值包含当前会话。多个窗口的重叠时间合并，项目有效时间也按项目合并。不是 Node 服务运行时间，不追溯旧版本的使用历史。

每约 15 秒回传，切页/隐藏/关闭时尽力立即保存；异常断电或强制结束浏览器可能丢失最后一个心跳。长时间休眠/定时器冻结按保守上限处理，不补算整段挂起时间；短暂发送失败仅重试最近两分钟片段。10 分钟空闲边界已用可控时钟测试，没有为了验收让用户电脑真实空等十分钟。

预设图片默认保存在数据目录 `preset-images/`，复用文件管理和备份机制。可以在存储设置迁移该目录；它是预设功能所需目录，可修改位置但不可移除。删除预设不自动清除图片文件；如通过文件管理删除真实图片，会提示仍有预设或历史记录引用，并可能影响对应图标显示。

运行 `npm test` 可执行当前 41 项隔离自动测试（含子测试）。阶段 6 当时为 22 项；阶段报告及具体验收边界见 `docs/PROGRESS.md`，界面已完成下文阶段 7 / 7.2 的设计。
